Sync Applied / Archive to GitHub

With a token, your Applied/Archive list is saved to data/marks.json in the repo, so it follows you to any browser or device that opens this dashboard with the same token.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Name: job-watch dashboard · Expiration: up to 1 year · Repository access: Only select repositories → job-watch
  3. Permissions → Repository permissions → Contents: Read and write (nothing else) → Generate, then copy it

The token is stored only in this browser. Anyone with it could edit this repo, so keep it scoped to job-watch only.
